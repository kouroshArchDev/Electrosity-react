# ELECTROSITY — Portfolio Production Build

A polished React + Vite e-commerce demo designed for a frontend portfolio.

## Run locally

1. Open this project folder in VS Code.
2. Open Terminal in the project root (the folder containing `package.json`).
3. Run:

```bash
npm install
npm run dev
```

4. Open the Local URL shown by Vite, usually `http://localhost:5173/`.

## Production build

```bash
npm run build
npm run preview
```

## Included

- Responsive homepage
- Product listing with search and category filters
- Product detail pages
- Functional cart with quantity controls
- Persistent cart using localStorage
- 404 handling
- Local product artwork for reliable image loading without external image hosts
- Portfolio-ready visual design

## Note

`node_modules` is intentionally not included. Run `npm install` once after extracting the project.
